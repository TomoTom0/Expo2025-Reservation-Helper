# プラットフォーム対応状況

## 1. サポートブラウザ

- **iOS**: Safari 15.4以降（iOS 15.4, iPadOS 15.4以降）
- **Windows**: Google Chrome（Manifest V3対応版）

## 2. Manifest V3 対応状況

| プラットフォーム | Manifest V3対応時期 | 備考 |
|-----------------|-------------------|------|
| Safari (iOS含む) | 2022年（Safari 15.4～） | すでに対応済み |
| Chrome | 2025年6月にV2完全終了予定 | 85%以上の拡張機能がV3移行済み |

本プロジェクトは **Manifest V3** を採用しています。

## 3. クロスプラットフォーム対応の意義

### iOS Safari特有の制約

| 制約事項 | 説明 | 対応 |
|---------|------|------|
| **非永続的バックグラウンドページ必須** | iOSのリソース制約により、永続的バックグラウンドページ不可 | Content Scriptのみ使用 |
| **App Store配布必須** | iOSアプリ内にバンドルして配布（または代替手段を使用） | Stayアプリ経由で配布 |
| **デフォルト無効（プライベートブラウジング）** | ページ情報にアクセスする拡張は無効 | ユーザーが手動で有効化 |
| **タッチイベント対応必須** | クリックイベントに300ms遅延がある | `@touchend.prevent`を併用 |

### 共通設計の利点

1. **単一コードベース**: iOS/PC両方を同じコードで実装
2. **メンテナンス効率化**: 機能追加・バグ修正を一度で完結
3. **UserScript互換**: Stayアプリ等のUserScript実行環境でも動作
4. **配布の容易さ**: zipファイル1つで複数プラットフォームに対応
